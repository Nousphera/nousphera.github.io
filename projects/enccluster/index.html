EncCluster: Scalable Functional Encryption in Federated Learning through Weight Clustering and Probabilistic Filters

Encrypt fewer values. Keep federated updates protected.

Vasileios Tsouvalas · Samaneh Mohammadi · Ali Balador · Tanir Ozcelebi · Francesco Flammini · Nirvana Meratnia

PaperPublished versionCodeCite
OverviewMethodFindingsCitation
The idea

At a glance

Secure aggregation can make federated learning expensive for devices with limited compute and bandwidth. EncCluster clusters model weights before functional encryption, then encodes the weight-to-cluster mappings with probabilistic filters, reducing the amount of data that must be encrypted and transmitted while allowing the server to reconstruct encrypted updates for aggregation.

  • Secure aggregation
  • Functional encryption
  • Weight clustering
Read the abstract

Federated Learning (FL) enables model training across decentralized devices by communicating solely local model updates to an aggregation server. Although such limited data sharing makes FL more secure than centralized approached, FL remains vulnerable to inference attacks during model update transmissions. Existing secure aggregation approaches rely on differential privacy or cryptographic schemes like Functional Encryption (FE) to safeguard individual client data. However, such strategies can reduce performance or introduce unacceptable computational and communication overheads on clients running on edge devices with limited resources. In this work, we present EncCluster, a novel method that integrates model compression through weight clustering with recent decentralized FE and privacy-enhancing data encoding using probabilistic filters to deliver strong privacy guarantees in FL without affecting model performance or adding unnecessary burdens to clients. We performed a comprehensive evaluation, spanning various datasets and architectures, to demonstrate EncCluster's scalability across encryption levels. Our findings reveal that EncCluster significantly reduces communication costs - below even conventional FedAvg - and accelerates encryption by more than four times over all baselines; at the same time, it maintains high model accuracy and enhanced privacy assurances.

The approach

How it works

  1. 01

    Cluster local model weights

    After local training, clients replace individual weight values with a compact set of cluster centroids and a mapping from weights to those centroids.

  2. 02

    Encrypt and encode

    Decentralized multi-client functional encryption protects the centroids. Binary Fuse filters encode the cluster-to-weight mappings as compact fingerprints, adding protection under the paper’s inference threat model.

  3. 03

    Reconstruct for secure aggregation

    The server queries the filters to recover the mappings and substitutes encrypted centroids for individual weights. Functional decryption then returns the aggregate model update.

From the paper

Key findings

Lower encryption and communication costs

The reported CIFAR-10 key-size study finds lower encryption time than SEFL and DeTrust-FL while keeping upstream communication below standard FedAvg. Compressing weights before encryption makes the number of encrypted values depend on the cluster count.

A visible privacy–efficiency tradeoff

Binary Fuse filters add communication compared with the variant that uses Huffman coding for mappings, but provide extra protection in the studied threat model. The component analysis reports little additional encryption time and similar model performance.
